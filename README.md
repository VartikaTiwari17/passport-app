## 🛠️ Tech Stack
- **Frontend**: React + Vite + Tailwind CSS + React Router + Axios
- **Backend**: Node.js + Express + SQLite + JWT Auth + Multer

## ✨ Features
- ✅ User registration & login with JWT
- ✅ 3-step onboarding for first-time users
- ✅ Multi-step application form with **autosave**
- ✅ Document upload (Aadhar, Photo, Address Proof)
- ✅ Appointment booking at Passport Seva Kendra
- ✅ Confirmation screen with downloadable receipt
- ✅ Dashboard with application status tracking

## ⚙️ Setup Instructions

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
